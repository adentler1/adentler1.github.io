# adentler1.github.io

Personal website of Alexander Dentler — applied economic theorist.

Live at **https://adentler1.github.io/**.

## Structure

- `index.html` — homepage (hero, featured work, selected research, projects, contact)
- `research.html` — publications and working papers (with chronological / topic sort, and abstract / bullets / titles-only display modes)
- `projects.html` — applied projects (Monitoring Mexico + subprojects, Soccer Contributions)
- `teaching.html` — teaching approach, courses, pedagogy
- `cv.html` — CV with PDF download options
- `css/style.css` — single stylesheet with light/dark mode via `prefers-color-scheme`
- `assets/` — PDFs, images, project logos

## Stack

Plain HTML + CSS, one small JS block on the research page for the sort/display toggles. No build step. Deployed via GitHub Pages from the `main` branch.

## Updates

Edit files directly on `main`. GitHub Pages rebuilds automatically within a minute.
